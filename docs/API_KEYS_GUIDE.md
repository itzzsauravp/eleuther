## 🔑 How to Add Keys to OmniRoute

### Method 1: Using the Config File (Recommended)

```bash
# 1. Copy the template
cp configs/api-keys.env.example ~/.omniroute/api-keys.env

# 2. Edit with your keys
nano ~/.omniroute/api-keys.env

# 3. Run the add-keys script
./scripts/add-keys.sh
```

### Method 2: One-by-One via CLI

```bash
# Add a single provider
omniroute providers add gemini --credential "YOUR_KEY_HERE" --yes

# Add no-auth provider
omniroute providers add aihorde --no-credential --yes
```

### Method 3: Interactive

```bash
omniroute providers add gemini  # Will prompt for key
```

## ⚠️ Important Notes

### Providers Requiring Credit Card / Deposit
Some providers require a credit card on file even for free tiers:
- **NVIDIA**: May require card for credits
- **Cerebras**: May require verification
- **SambaNova**: May require verification
- **Baseten**: May require card

**Always check the provider's current policy before signing up.**

### Daily vs Monthly Resets
| Reset Type | Providers |
|------------|-----------|
| **Daily** | Gemini (1500/day), Groq (30/min = ~43k/day) |
| **Monthly** | NVIDIA (1000 credits/month) |
| **Continuous** | No-auth providers, most pass-through routers |
