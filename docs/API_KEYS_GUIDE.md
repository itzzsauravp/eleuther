## 🎯 Recommended Setup Order

To maximize your free tokens quickly:

1. **Start with no-auth providers** (zero setup)
   - aihorde, opencode, huggingchat, firecrawl, searxng-search

2. **Get Tier 1 API keys** (highest token limits)
   - Gemini, Groq, NVIDIA, Cerebras, SambaNova, DeepSeek, Mistral, Cohere, HuggingFace, DeepInfra

3. **Add Tier 2 providers** (more tokens)
   - Fireworks, Nebius, SiliconFlow, Hyperbolic, Featherless, FriendliAI, nScale, Baseten

4. **Add pass-through routers** (one key = many models)
   - OpenRouter, Requesty, AnyAPI, Freebuff

5. **Configure OAuth providers** (if you have accounts)
   - Claude Code, GitHub Copilot, Cursor, Kiro AI, Amazon Q

## ⚠️ Important Notes

- **Never share your API keys** — keep them private
- **Free tiers change** — check provider websites for current limits
- **Some providers need phone verification** — be prepared
- **Rate limits vary** — OmniRoute handles this automatically
- **Some providers are region-locked** — use VPN if needed
